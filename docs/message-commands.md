# 消息指令映射

指令是消息正文的匹配条件与数据映射，复用连接、路由和持久化投递。QQ 等平台的指令面板只负责展示入口；平台适配器收到消息后，仍由 Synquay 的规则决定实际动作。

## 管理台配置

在「路由 → 新建 / 编辑 → 处理」勾选「指令映射」：

1. 选择来源连接，例如 Webhook 或 MQTT 订阅。
2. 指定消息字段，使用 JSON Pointer：`/content`、`/text` 或 `/payload/content`。空字符串表示消息载荷本身是 JSON 字符串。单一 Text 内容的内部 Message 也可以匹配。
3. 选择全文匹配或指令与参数，填写触发文字。
4. 保留原始内容，或映射为新的事件类型和 JSON 消息。
5. 选择处理方式与目标，保存后启用。

接入层负责 QQ 的验签、去重、用户/群/会话识别和必要的 @机器人文本规范化。通用指令模块不猜测平台身份，不剥离任意 @ 文本，也不把消息内容当作权限。

当前处理方式：

- **转发**：发送至已配置的 HTTP 或 MQTT 出口，可向多个目标投递。

## 匹配语义

匹配大小写敏感，比较前去除整条消息首尾空白。

- `exact`：全文一致，例如 `设备状态`。
- `prefix`：完整指令后必须为空或空白字符。例如 `/助手 安排今晚任务` 命中 `/助手`，参数为 `安排今晚任务`；`/助手别名` 不命中。
- 空指令、不合法的 JSON Pointer 会在保存时拒绝；缺失字段、非字符串、二进制、外置内容和多个 Message 内容部分不匹配。
- 入口、事件类型和指令条件同时满足才会执行。
- **所有命中的启用路由都会执行**，不是按列表顺序只取第一条。配置专用指令时，检查同一入口已有的全量转发路由，避免不需要的额外投递。
- 不支持正则、脚本、Shell 模板或任意表达式执行。

## JSON 映射

消息：

```json
{"content":"/开启 热水器","room":"kitchen"}
```

指令配置：

```json
{
  "text_pointer": "/content",
  "trigger": "/开启",
  "mode": "prefix",
  "output": {
    "kind": "json",
    "event_type": "device.command",
    "template": {
      "action": "turn_on",
      "device": {"$command": "arguments"},
      "room": {"$payload": "/room"}
    }
  }
}
```

输出载荷：

```json
{"action":"turn_on","device":"热水器","room":"kitchen"}
```

模板引用是独立 JSON 对象，不是字符串拼接：

| 引用 | 值 |
| --- | --- |
| `{"$command":"arguments"}` | 指令后的剩余文本 |
| `{"$command":"text"}` | 去除首尾空白后的完整文本 |
| `{"$command":"trigger"}` | 配置的触发文字 |
| `{"$payload":"/room"}` | 原始 JSON 字段，保留其类型 |

引用对象不能混合其他字段。来源值不会再次作为模板执行。引用字段缺失、模板非法或输出过大时，该事件的路由分发失败，不产生部分目标投递，沿用现有失败记录和恢复流程。

HTTP/MQTT 的 Payload 模式发送映射后的载荷，Event 模式发送带事件标识的封装。原始持久化事件不修改，事件 ID 与上游 ID 保留；输出事件类型不重新进入路由匹配，避免隐式递归。

## 持久化与边界

指令属于 `ManagedRoute.command`，复用路由快照与操作回执，不引入新的数据库表和索引。管理台沿用按入口过滤与分页；运行时遍历有上限的完整路由快照（64 条），不受界面分页影响，也不逐消息扫描数据库全文。

API 保存中省略 `command` 保留既有映射，显式 `null` 删除映射，兼容旧客户端启停和改名。指令配置随路由删除，连接删除继续清理引用。规则在分发时读取，已进入投递队列的消息保留当时映射出的内容。

模板最大 8 KiB、深度 32，匹配文本和生成 JSON 分别最大 64 KiB。转发仍受连接线协议大小、工作区容量及投递重试约束。映射只能改变消息内容，不能指定凭据、跨空间目标、执行身份或未经配置的地址。

### QQ 群名称

QQ 群消息可通过 `{"$payload":"/group_name"}` 在 JSON 输出模板中引用群名称；未取得名称时该字段为 `null`。直接转发会保留原消息字段；自定义模板只输出模板中选定的字段。
